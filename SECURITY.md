# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in GuardScan, please report it responsibly.

**Do NOT open a public GitHub issue.** Instead, email us directly:

- **Email:** support@arkprivate.com

We will respond within 48 hours and work with you to resolve the issue privately.

## Supported Versions

| Version | Supported |
|---------|-----------|
| Latest (main branch) | ✅ Yes |

## Disclosure Process

1. You report the vulnerability privately via email.
2. We acknowledge receipt within 48 hours.
3. We fix and release a patch.
4. We credit you in the release notes (if you wish).
